# Source map

This library should stay anchored to official documentation. Time-sensitive doctrine belongs in references or this source map rather than being copied loosely across many skills.

## How to read this

- **Primary doctrine** — sources the library should treat as foundational.
- **Operational references** — sources that support a concrete audit or suggestion skill.
- **Explanatory Google posts** — supporting context for why the library prefers certain shapes; useful for doctrine, usually not enough on their own to justify a skill.
- **Skill-authoring references** — how the library itself is structured.

## Explanatory Google posts

These are useful doctrine support, but should usually reinforce a reference rather than create a skill on their own.

- How AI powers great search results  
  https://blog.google/products-and-platforms/products/search/how-ai-powers-great-search-results/
  - supports concept-based retrieval, language understanding, and the weakness of exact-match thinking
- How AI is powering a more helpful Google  
  https://blog.google/products-and-platforms/products/search/search-on/
  - supports passage understanding, subtopics, and multimodal interpretation
- New ways we're helping you find high-quality information  
  https://blog.google/products-and-platforms/products/search/information-literacy/
  - supports reliability, source context, consensus, and data-void awareness
- How Google delivers reliable information in Search  
  https://blog.google/products-and-platforms/products/search/how-google-delivers-reliable-information-search/
  - supports relevance-versus-reliability, trust-sensitive topics, and stronger quality expectations
