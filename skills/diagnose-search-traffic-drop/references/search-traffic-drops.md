# Search traffic drops

Use this when investigating a decline in organic Google Search traffic.

## Main causes Google documents

- algorithmic updates
- technical issues
- security issues
- spam issues
- seasonality or changing interests
- site moves and migrations

## Core analysis steps

- inspect the Search Console Performance chart
- use a broad enough date range to spot seasonality
- compare the drop period with a similar prior period
- analyze search types separately
- review average-position changes without over-focusing on the absolute number
- look for patterns in affected pages
- use Google Trends to distinguish site-specific decline from wider demand change

## Reporting guidance

- Keep causal claims proportional to the evidence.
- Separate site-wide drops from page-group or single-page drops.
- Hand off technical, spam, or security causes to the relevant specialist audit once identified.
