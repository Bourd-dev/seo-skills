# AI search guidance

Use this to keep the library honest about generative-search work.

## Working assumptions

- Treat visibility in generative search as downstream of strong search fundamentals.
- Use query fan-out to widen research, not to mass-produce thin pages for every phrasing.
- Favor unique, non-commodity information and clear technical structure over speculative hacks.
- Prefer coherent pages with useful passages and meaningful subtopics over fragmentation created only to chase phrasing variants.
- Multimedia can create additional visibility surfaces when it genuinely helps the page.
- Treat structured data as standard SEO support for eligible search features, not as a requirement for generative AI visibility or a place to invent AI-specific markup.

## Anti-patterns

Do not recommend these as necessary tactics for Google Search:

- creating `llms.txt` files solely to appear in generative features
- chunking pages only for AI systems
- rewriting copy into an imagined AI-specific dialect
- manufacturing inauthentic mentions
- adding structured data that is irrelevant or invisible on the page
- presenting any of the above as a substitute for crawlable, indexable, useful pages

## Agentic frontier

When the business benefits from browser agents, inspect semantic HTML, labels, stable layouts, accessibility tree clarity, and actionability. Treat this as a usability and machine-readability concern. It does not replace SEO fundamentals.
