# On-page signals

Use this when auditing the signals a page gives about its own subject and likely search appearance.

## Core checks

- Titles, visible headings, prominent page text, and link context should describe the same page rather than pulling in different directions.
- Title links are influenced by multiple sources, including `<title>`, visible headings, prominent text, anchor text, and structured data.
- Snippets are primarily derived from on-page content; meta descriptions can help when they describe the page better than surrounding text.
- Link text, image alt text, and headings should clarify meaning for people first, not merely echo keyword lists.
- Main content should be easy to distinguish from surrounding chrome, ads, or boilerplate.

## Evidence to preserve

- `<title>`
- H1 and prominent visible title
- meta description
- representative anchor text pointing to and from the page
- conflicting or duplicate examples
- snippet risk where the page's own text is vague, stale, or misleading

## Reporting guidance

- Do not promise exact SERP rewrites; describe signal quality and mismatch risk.
- Separate duplication from poor description.
- Prefer concrete examples over abstract style guidance.
