# Query performance

Use this when turning Search Console query data into optimization opportunities.

## Core dimensions

- click-through rate
- average position
- clicks
- query
- device when it changes the interpretation

## Query groups documented by Google

1. **Top position, high CTR**
   - generally performing well
2. **Low position, high CTR**
   - relevant queries where stronger pages or fuller coverage may materially help
3. **Low position, low CTR**
   - inspect whether the query is related and worth pursuing before investing
4. **Top position, low CTR**
   - inspect search appearance, relevance, or cases where users already got the answer they needed

## Reporting guidance

- Use the quadrants to prioritize investigation, not as a substitute for judgment.
- Prefer large or strategically relevant bubbles over tiny edge cases.
- Distinguish page creation from page improvement when the query already has a matching page.
- Use device differences as an additional sign when they materially change interpretation.
