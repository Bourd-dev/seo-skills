# Media SEO

Use this when auditing image and video visibility surfaces.

## Images

- Prefer standard HTML image elements when the image should be discovered.
- Preserve descriptive alt text where it helps users understand the image.
- Check whether important images are crawlable, indexable, relevant, and actually embedded in the page rather than only painted through CSS.
- Pair image findings with helpful-content judgments when the media adds genuine value rather than decoration.

## Video

- Videos should be discoverable in the rendered page through standard embedding patterns.
- Important videos need stable, indexable watch pages when video features matter to the business.
- Watch pages should have unique titles and descriptions appropriate to the video.
- Video discoverability can depend on thumbnails, metadata, and whether the media is hidden behind interactions or inaccessible containers.

## Reporting guidance

- Treat image and video as distinct search surfaces.
- Distinguish "media exists" from "media is eligible and discoverable."
- Report when media adds no clear user value instead of assuming more assets are always better.
