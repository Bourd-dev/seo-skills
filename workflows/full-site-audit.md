# Full site audit workflow

Use this workflow when the user wants one unified audit across the site's major SEO surfaces.

```text
audit-site-overview
-> technical audit path
-> discoverability and deservingness path
-> conditional extensions as relevant
-> merge-audit-findings
```

## Sequence logic

1. Map the site and choose representative scope.
2. Run the technical spine first when eligibility is uncertain.
3. Add discoverability, content, and spam-policy audits once the basic surface is understood.
4. Add conditional audits only when the site or business model makes them material.
5. Merge all findings into one report before asking the suggestion arm what to do next.

## Conditional extensions

- `audit-search-performance`
- `audit-media-seo`
- `audit-structured-data`
- `audit-business-presence`
- `audit-ecommerce-readiness`

## Final synthesis

Return:

- one executive summary
- one priority table
- one merged findings set
- one dependency-aware fix sequence
- one list of unknowns
